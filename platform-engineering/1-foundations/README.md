# Level 1: Foundations

These modules teach the mesh basics that every later module builds on, so start here if Istio is new to you. You need only the running lab, and module 0 checks it and installs `istioctl`. Take the modules in order, read module 29 after module 7 to tie the pieces together, and finish with module 8 to test yourself. Module 9 is a reference to keep open while you work.
